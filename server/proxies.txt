# Agar.io Bot Proxy List
# One proxy per line. Formats supported:
#   socks5://user:pass@host:port   (recommended)
#   socks5://host:port
#   http://user:pass@host:port
#   http://host:port
#   host:port                      (defaults to socks5)
#   host:port:user:pass            (defaults to socks5)
#
# Agar.io limits ~5 WebSocket connections per IP.
# For 10 bots you need at least 2 proxies.
# For 50 bots you need at least 10 proxies.
#
# Residential proxies are recommended (datacenter IPs get banned faster).
# Providers: brightdata.com, smartproxy.com, iproyal.com, proxy-seller.com
#
# Example:
# socks5://username:password@proxy1.example.com:1080
# socks5://username:password@proxy2.example.com:1080
# http://username:password@proxy3.example.com:8080
